# Ishami Legacy Apartments — Version 2

## Included
- Multiple apartment listings with prices and details
- Estimated booking total by nights
- Booking requests stored locally in browser demo
- Guest photo upload (optional)
- Admin dashboard
- Confirm / cancel / delete bookings
- Add / delete apartment listings
- Add / delete gallery photos
- WhatsApp booking handoff
- Responsive design

## Important production note
This ZIP is a **working front-end prototype**. The admin password and all data are browser-side and are NOT secure for a public website. For real deployment, connect the project to Supabase/Firebase and use secure authentication, database storage, server-side availability checking and secure object storage for customer photos.
